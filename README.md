# Pista

Mobile-first Trainingsplaner für GitHub Pages. Helles Design, Trainingsplan-Import, lokale automatische Speicherung, Fortschritt und DIN-A4-PDF-Export.

Die App wird ohne externes Backend betrieben. Persönliche Trainingsdaten bleiben im Browser und werden nicht in dieses öffentliche Repository geschrieben.

Website (nach Aktivierung von GitHub Pages): https://kaikmedia-create.github.io/Pista/
